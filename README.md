# Udhekryqi Filma

Udhekryqi Filma is a local-only visual demonstration catalogue. It contains a small set of fictional placeholder movies, does not provide playback, and does not connect to a catalogue, authentication service, email provider, or database.

## Local development

```bash
pnpm install
pnpm dev
```

Then open `http://localhost:3000`.

## Checks

```bash
pnpm typecheck
pnpm test
pnpm build
```
